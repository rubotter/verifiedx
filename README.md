<h1 align="center">VerifiedX</h1>
<p align="center">在浏览器侧栏整理自己的 X 关注与粉丝。</p>
<p align="center">v1.0.0 · 作者 <a href="https://x.com/gegesobig">@gegesobig</a> · 数据保存在本地 · Chrome 扩展</p>

VerifiedX 仅扫描 **当前登录的 X 账号**。你可以找出未回关的人、尚未关注的粉丝，按认证类型筛选，并在列表中单个关注或取关。

## 功能

- **双列表筛选**：关注列表筛选未回关；粉丝列表筛选我未关注、我已关注。
- **认证分类**：未认证、蓝 V、企业认证、政府认证及未知，可与关系条件和昵称／用户名搜索组合。
- **自动采集**：关注通过 API 分页；粉丝通过网页自动滚动加载，支持暂停与继续。
- **单账号操作**：关注、取关；取关后独立查询关系确认结果，未知结果可重新验证。
- **首次发现记录**：本地记录关注账号首次出现的时间，建立基线后标记本次新增。它不是实际关注日期。
- **深浅色侧栏**：显示当前账号，支持切换主题。没有 CSV 导出或批量关注／取关。

## 安装

需要 Chrome 116 或更新版本。Edge 需要支持 `sidePanel`，目前未做 Edge 实机验证。

### 使用发布包

如果仓库 Releases 已提供 `VerifiedX-版本号.zip`：

1. 下载并解压安装包。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包内的 **`extension/`** 文件夹，其中应直接包含 `manifest.json`。
4. 固定 VerifiedX 图标，打开并刷新已登录的 X 页面。

### 从源码构建

安装 Node.js **22.12+（22.x）或 24+**，在项目目录运行：

```sh
npm ci
npm run build
```

然后按上面的步骤加载本项目的 `extension/`。侧栏编译产物不提交到 Git，**下载源码后必须先构建**；使用发布包则无需 Node.js。

## 开始使用

1. 登录 X，点击扩展图标打开侧栏。
2. 选择「我的关注」或「我的粉丝」，开始扫描；扩展核对本人账号后进入相应列表。
3. 保持扫描标签页可见。粉丝自动滚动时，页面提示层提供暂停入口。
4. 使用关系、认证分类和搜索筛选结果。可补采另一类列表，改善关系判断。
5. 按需单个关注或取关。结果是扫描快照，关系发生变化后可重新扫描。

更新时覆盖原扩展目录，点击扩展管理页的「重新加载」，并刷新 X 页面。**不要先卸载**，否则会丢失本地记录。

详细操作与判断规则见 [使用说明](docs/USAGE.md)。

## 已知限制

- 依赖 X 网页内部接口与响应结构，不是 X 官方产品，也不保证线上接口长期兼容。当前验证以本地模拟测试为主，真实账号全量采集仍需实测。
- 关注分页可能遇到 401、403、404 或 429；粉丝采集依赖网页滚动与加载。错误时保留已采集结果。
- **“采集完成”不一定表示服务端已明确返回末页。** 当前空页或粉丝底部停滞也可能触发完成，慢加载可能导致提前停止，影响基于完整列表推算的关系和历史基线。
- 未知状态单独保留；“非蓝 V”包括企业／政府认证，不等于“未认证”。
- 取关结果依赖独立查询验证；无法确认时保留待核对状态，不把 HTTP 成功直接当作操作成功。

## 隐私与权限

没有自建服务器或分析服务。扫描结果、首次发现历史保存在 `chrome.storage.local`；采集和关系操作会与 X 通信，显示头像也可能访问其图片服务。

扩展使用 `storage` 保存数据、`sidePanel` 展示界面、`webRequest` 临时取得必要请求头，以及 X / Twitter 域名访问权限。认证头仅用于内存中的请求，不保存到本地存储。详见 [数据与权限](docs/PRIVACY.md)。

## 开发

```sh
npm test               # 逻辑测试
npm run build          # 构建侧栏
npm run test:browser   # 模拟浏览器回归，需先安装 Chromium 和 OpenSSL
npm run build:icons    # 从正式 SVG 生成图标，需 Chromium
npm run package        # 构建并打包，另需 Python 3
```

环境准备、目录职责与发布步骤见 [开发说明](docs/DEVELOPMENT.md)。

```text
assets/brand/    正式 Logo 的 SVG 与高清 PNG
extension/      扩展清单、后台、内容脚本及运行图标
src/            Svelte 侧栏源代码与样式
scripts/        图标生成与发布打包脚本
tests/          逻辑测试与本地模拟浏览器回归
docs/           使用、隐私及开发文档
dist/           生成的安装包和校验文件（不提交）
work/           本地调试、测试截图与历史归档（不提交）
```
