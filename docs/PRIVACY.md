# 数据与权限

- `storage`：保存当前扫描结果及按账号隔离的首次发现历史到当前浏览器本地。
- `sidePanel`：显示工具侧边栏。
- `webRequest`：从列表请求中临时取得单账号操作所需的白名单认证头，不读取 Cookie。
- `https://x.com/*`、`https://twitter.com/*`：识别自己的个人资料入口，观察本人资料、关注/粉丝响应，并在授权期间滚动本人的粉丝页、请求本人的关注分页。
- 分页请求沿用网页已发送的请求头（可能包含 Authorization 和 CSRF 信息），仅保存在该页面的内存中，不写入扩展存储、不导出。Cookie 由浏览器自动附带，不直接读取。未接入独立的官方 API 客户端，不使用云端服务。
- 单账号写操作由扩展后台通过内部消息授权，只在本页扩展隔离环境中执行。所需认证头由扩展网络观察接口取得，仅暂存在后台内存，通过扩展内部消息交给隔离环境，不经网页消息传递、不落盘；操作完成后清除隔离环境的临时引用。网页消息不能发起写入或作为操作成功的凭据。
- 采集请求仅发送到同源列表接口；点击关注或取关按钮才向同源关注接口提交单账号 POST；取关后自动 GET 复核，「重新验证」只发 GET。没有自动批量关注或取关，不绕过限流。用户点开主页是普通网页导航。
- 「清空本次结果」仅删除本次快照，首次发现历史保留；「删除当前账号历史及结果」另行删除当前账号历史。
