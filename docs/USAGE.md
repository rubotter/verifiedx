# 使用说明

## 使用

1. 打开 `https://x.com` 并登录要筛选的账号。**安装或重新加载扩展后，先刷新 X 页面。**
2. 等待 X 左侧的「个人资料」入口出现，点击工具栏上的扩展图标打开侧边栏。
3. 在顶部选择「我的关注」或「我的粉丝」，点击对应扫描按钮。扩展先打开你的个人资料页核对账号，成功后自动进入选定列表。已有会话时，侧栏会先显示「确认开始扫描」和「取消」；确认前不替换数据。
4. 默认开启自动采集，请保持 X 扫描标签页可见。粉丝视图显示「自动滚动采集」：首屏加载后，每次向下滚动约 80% 视口，间隔至少 3 秒，由网页自己加载下一页。控制提示层显示当前账号，可直接点击「暂停采集」。关注视图显示「自动分页采集」：通过 API 串行请求下一页，页面不滚动。取消勾选后仅采集手动滚动加载的结果。
5. 选择筛选条件，再用「认证分类」选择未认证、蓝 V、企业认证或政府认证，可与未回关（关注视图）、我未关注（粉丝视图）和搜索条件叠加。无法确定类别的账号单独归入「认证未知」。
6. 点击「扫描关注」或「扫描粉丝」可在同一会话补采另一类列表，保留两份快照；自动采集勾选开启时，粉丝自动滚动，关注通过 API 自动分页。顶部切换只查看已采集结果，不会发请求。「重新扫描」会替换两份本次结果，首次发现历史保留。

当前版本除连续分页与明确末页外，也会将关注空页、符合条件的粉丝空页判为完成；粉丝两次向下滚动无法移动且位于底部、至少 5 秒无进展时也会判为完成。这些启发式条件可能在慢加载或异常空响应时提前触发。限流、加载错误及未触发完成条件的持续无进展会停止并保留结果。关注 API 请求间隔至少 3 秒，另有 15 秒请求超时和 20 秒后台等待超时。

自动采集期间请保持该标签页可见。切换标签页、离开正在采集的列表、暂停采集、切换账号都会停止自动活动。点击「继续采集」会打开顶部选择的列表；勾选自动采集时，粉丝从网页首屏重新滚动并合并去重，关注从连续分页链缺失处请求；未勾选则只恢复手动采集。已完成的列表显示「该列表已完成」，更新结果请重新扫描。

扩展绑定开始扫描时的那个标签页。其他标签页不会写入本次结果。账号变化会暂停采集。原扫描标签页关闭后，打开同账号的 X 页面，点击「继续采集」或扫描列表快捷入口即可重连，保留两份列表与首次发现历史；未登录或账号不一致会拒绝重连。

扩展会先在本人的个人资料页将用户名与数字账号 ID 核对，再跳转到选定的关注或粉丝列表。核对结果保存在后台，跳转页面后不会丢失，不要求关注列表再次请求个人资料。一直显示「核对账号中」时，请刷新本人资料页；若仍无法确认，将保持不采集，而不会猜测账号身份。

### 粉丝筛选

选择「我的粉丝」后，可按「我未关注」「我已关注」「非蓝 V」「我未关注 & 非蓝 V」或「状态未知」筛选，再叠加未认证、蓝 V、企业认证、政府认证等类别。

「我未关注」指你尚未关注这个粉丝。先使用页面明确返回的 following 字段或本次单账号操作结果；缺少字段时，关注列表中的账号可确认已关注，只有完整关注列表差集才能确认未关注。部分关注列表中没找到的账号保持未知；已发送关注申请的账号不混入未关注。较新的粉丝关系字段可覆盖较旧的关注快照。

粉丝卡片可直接单个关注或取关，未知状态不允许操作。粉丝视图不记录关注首次发现历史、不标记关注新增。

### 单个关注与取关

采集后，点击账号卡片的「取关」即可操作该账号；成功后卡片保留在本次快照中，按钮变为「关注」，方便关注回来。操作仅使用开始扫描时绑定的登录账号，扫描标签页需停留在本人的关注或粉丝列表。

每次点击只提交一个账号的操作。操作前会暂停采集，列表仍显示本次快照中的账号；数量不代表实时关注总数。成功后更新「我的关注状态」，不会改变表示对方是否关注你的「回关状态」。

取关后显示「正在验证」，等待约 1 秒查询当前账号对目标账号的关注关系。仍在关注或查询结果不明确时，每隔 3 秒再查，最多 3 次；每次查询最多等待 6 秒。确认后显示「已取关 · 已验证」，悬停可查看验证时间。三次后仍关注会明确提示「仍在关注 · 已验证」。查询遇到 401、403、429 立即停止。

取关结果未知时可点击「重新验证」，只查询状态，不重复提交取关；刷新侧栏或中断后也可重试查询。验证记录代表该时间点的关系，不会持续追踪。旧版本没有保存操作类型的未知记录仍需在 X 核对。私密账号的关注申请显示「已申请」；关注结果不明确时禁止重复提交，需要打开主页核对。

### 首次发现时间与新增徽章

关注视图的账号卡片显示「首次发现」时间，按当前登录账号和被关注账号的数字 ID 保存在本地；改用户名、重新扫描、关闭浏览器不会重置时间。这个时间表示插件最早记录到该账号，不是实际开始关注的时间。

第一次完整关注列表扫描建立历史基线；完成前只记录时间，不显示新增。基线建立后的扫描中，此前从未出现的账号显示绿色「新增」徽章，可选择「本次新增」筛选。徽章在该次扫描内保留（包括暂停、刷新侧栏），下次扫描不再标记旧账号。取关后重新关注的已知账号也不会当作首次新增。

升级前保留的旧快照会以其中现存的采集时间迁移，无法还原更早的首次发现时间；已经清空的旧记录无法补回。

「清空本次结果」保留首次发现历史。要删除当前扫描账号的历史，在「说明与依据」中点击「删除当前账号历史及结果」；确认后删除该账号的历史和当前快照，下次重新建立基线，其他账号历史保留。卸载扩展也会丢失本地历史。

## 如何判断

| 状态 | 依据 |
| --- | --- |
| 已回关 | 页面明确返回 `followed_by: true`，或本次粉丝列表包含该用户 |
| 未回关 | 页面明确返回 `followed_by: false`，或被当前版本标记为完整的本次粉丝列表不包含该用户 |
| 蓝 V | 明确的蓝 V 字段或认证类型，企业/政府认证优先单独识别 |
| 未认证 | 明确 None 类型，或非蓝 V 且明确 verified 为 false；存在已认证或未知类型证据时保留未知 |
| 企业认证 | 认证类型为 Business，优先于蓝 V 字段 |
| 政府认证 | 认证类型为 Government，优先于蓝 V 字段 |
| 非蓝 V | 蓝 V 字段明确为 false，或明确为其他认证类型 |
| 未知 | 字段缺失、无法识别，或粉丝列表尚无完整证据 |

优先识别新版 `verification.verified_type`，兼容顶层、`legacy` 和 `ext_verified_type` 中的类型字段。黄标 Business 归为企业认证，灰标 Government 归为政府认证。仅有 `is_blue_verified: false` 时可确定非蓝 V，但认证类别保持未知。

不会把 `verified: false` 单独当成「非蓝 V」证据，也不会把“未采集到某人”直接当成未回关。未知状态不会混入未回关或非蓝 V 筛选。
